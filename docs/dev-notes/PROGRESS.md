# PROGRESS

## Setup
- Python 3.12 venv at `.venv` (system python3 is 3.9, too old). Create with:
  `uv venv --python 3.12 .venv && uv pip install --python .venv/bin/python -r requirements.txt`
- Run tests: `.venv/bin/python -m pytest -q`. Run app: `.venv/bin/python -m uvicorn app.main:app`, open http://localhost:8000/.
- Offline (no key, no cost) checklist and cards: `GATE_MODEL=fake:keyword CUE_MODEL=fake:template .venv/bin/python -m uvicorn app.main:app`.
- Cost and latency report: `.venv/bin/python -m app.report [--experiment X] [--csv out.csv]`.
- Real-gate smoke test (paid, ~$0.05): `.venv/bin/python -m tests.smoke_gate`.

- **Jev thresholds and confidence** (2026-10-08, run `sessions/gate-compare-20261008-004440.json`, offline analysis `python -m tests.analyze_jev <file>`, no extra paid calls).

  - Research (docs.typesafe.ai): one condition per yes/no question, combine in code; choice answers carry `confidence` (1 = all probability on one option); for yes/no use `|2p-1|`; "confidence-gated routing" is a documented pattern; pick thresholds per action from labelled data.
